# Study Mate
http://127.0.0.1:5501/index.html
공부 시간을 기록하고 데이터를 분석할 수 있는 웹 프로젝트입니다.  
공부 시간 데이터를 확인하고 관리하며, 전체 공부 시간과 관련된 요약 정보를 확인할 수 있습니다.

## 1. 프로젝트 소개

Study Mate는 공부 시간 데이터를 바탕으로 학습 기록을 관리하고 분석하는 서비스입니다.

Python으로 데이터를 생성하고 분석하며, FastAPI를 이용해 데이터를 처리하는 백엔드를 만들었습니다.  
HTML 화면에서는 공부 시간 데이터를 확인하고 추가하거나 수정 및 삭제할 수 있습니다.

## 2. 주요 기능

### 공부 시간 데이터 관리
- 공부 시간 데이터 조회
- 새로운 공부 기록 추가
- 기존 공부 기록 수정
- 공부 기록 삭제

### 데이터 분석
- 공부 시간 데이터 요약 확인
- 생성된 공부 시간 데이터 분석

### 웹 화면
- 브라우저에서 공부 기록 확인
- 백엔드 API와 연결하여 데이터 표시
- 공부 기록 추가 및 삭제 기능 제공

## 3. 사용 기술

| 구분 | 기술 |
|---|---|
| 프로그래밍 언어 | Python |
| 백엔드 | FastAPI |
| 프론트엔드 | HTML |
| 데이터 저장 | CSV |
| 개발 환경 | Visual Studio Code |
